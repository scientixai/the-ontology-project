Safety & pharmacovigilance

Adverse events and serious adverse events, with the expedited 15-day reporting clock measured bitemporally (awareness → submission).

An event’s seriousness and the sponsor’s awareness date start a 15-day expedited clock — measured on the timeline, so a late report is a query that fires, not a surprise at inspection.

One NGSI-LD query assembles the screen — join=inline follows the relationships forward, so the whole object returns in a single read.

GET /ngsi-ld/v1/entities/urn:ae-001?join=inline&joinLevel=3
Accept: application/ld+json
Link: <https://top.scientix.ai/cr/v1/ngsi-context.jsonld>; rel="http://www.w3.org/ns/json-ld#context"

# ETSI GS CIM 009 Linked Entity Retrieval: join=inline embeds each linked
# Entity as the `entity` sub-attribute of its Relationship (clause 4.5.23.2);
# joinLevel follows relationships FORWARD only (clause 4.5.23.1). Every fact
# is forward-reachable from this entity -> ONE stock-broker call, no recursive
# lookups. cr:AdverseEventView is the attribute projection (the `pick` the screen reads).

How the flow runs — step by step

1
AE onset2026-02-09subject / site
  • ✓ recorded with onset date/time
2
Seriousness assessed2026-02-09investigator
  • ! meets a serious criterion → becomes an SAE
3
Sponsor aware2026-02-10sponsor PV
  • ✓ awareness date starts the 15-day clock
4
Expedited report2026-02-18sponsor
  • ✓ submitted on day 8 — within the window

The 15-day SAE reporting clock is a bitemporal compliance check (a detective query over awareness vs submission), not a structural shape — the structure stays valid; the timeline is the signal.
