Glossary

Two glossaries in one: the terms of art an outsider needs to read clinical research, and the model's own vocabulary (pulled live from the ontology, so it never drifts).

Clinical-research terms & acronyms

termmeaning
ALCOA++Attributable, Legible, Contemporaneous, Original, Accurate (+ Complete, Consistent, Enduring, Available) — the data-integrity properties GCP expects of source data.
CAPACorrective And Preventive Action — the response opened when a significant deviation occurs.
CtQCritical-to-Quality factor — an aspect of the trial whose integrity is essential; the unit RBQM assesses risk against.
CSRClinical Study Report (ICH E3) — the definitive narrative of a study's conduct and results.
CTAClinical Trial Agreement — the executed contract between sponsor and site; a gate for activation.
DoA / DOADelegation of Authority log — who the PI delegated which task to; here a projection of attestation acts, not a maintained spreadsheet.
DTA / DTSData Transfer Agreement / Specification — governs non-CRF vendor data (labs, ECG, imaging, eCOA).
eCTDelectronic Common Technical Document — the submission format; Module 5 carries the clinical study content. The terminal node of this domain.
EDCElectronic Data Capture — the system CRF data is entered into; modeled here as CDISC ODM EAV capture.
EOP2End of Phase 2 — the go/no-go decision gate that yields a Phase 3 design.
estimandA precise description of the treatment effect a trial estimates (ICH E9(R1)): population, variable, intercurrent-event strategy, summary.
IND / IDEInvestigational New Drug / Investigational Device Exemption — the FDA applications that authorize first-in-human study.
IxRS / RTSMInteractive Response System / Randomization & Trial Supply Management — randomization and drug-supply logistics (a deferred sub-domain).
KRIKey Risk Indicator — a monitored metric that signals emerging risk in RBQM.
LPLVLast Patient Last Visit — the milestone that opens database closeout.
MedDRA / WHODrugMedical Dictionary for Regulatory Activities / WHO Drug Dictionary — the coding terminologies for adverse events and medications.
NGSI-LDETSI GS CIM 009 — the JSON-LD-over-RDF entity API and preferred runtime substrate; observedAt is native.
PROVW3C PROV-O — the provenance vocabulary (wasAttributedTo, wasDerivedFrom) the model uses for attestation and lineage.
RBQMRisk-Based Quality Management — targeting monitoring effort by risk rather than blanket 100% SDV.
SAE / SUSARSerious Adverse Event / Suspected Unexpected Serious Adverse Reaction — the safety events on the expedited reporting clock.
SAPStatistical Analysis Plan — pre-specifies the analyses; a TLF is legitimate only if grounded in it.
SDTM / ADaMStudy Data Tabulation Model / Analysis Data Model — CDISC submission datasets; here they are projections (views) of the native graph, not the source of truth.
SDVSource Data Verification — checking CRF values against source; intensity is risk-targeted in RBQM.
SIVSite Initiation Visit — the readiness gate before a site may enrol.
SoASchedule of Activities — the visit-and-assessment schedule; modeled as a bitemporal timeline, not a flat 2D table.
SSSOMSimple Standard for Sharing Ontological Mappings — the format the external crosswalks follow (predicate, justification, confidence, provenance).
TLF / TFLTables, Listings and Figures — the analysis outputs; each must be reproducible-to-source and pre-specified in the SAP.
TMF / eTMFTrial Master File — the regulated document store; artifact types align by name to the DIA TMF Reference Model.
USDMUnified Study Definition Model (CDISC DDF) — the design-time study model this domain crosswalks to; devices stay in-model per USDM.
